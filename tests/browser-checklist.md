# 浏览器验收

使用自己拥有的采样生成单文件HTML，在浏览器打开。不要只验证按钮存在：

1. 导入两个NBS（一个普通文件，一个新版），没有sidecar也自动显示音色与层数。
2. 点击播放可推进时间；暂停停住；seek定位，声音保留自然衰减。
3. 独奏/静音对同一位置生效，音量不被自动提高；切换按层/音色后清空旧选择。
4. 选对比曲，A/B保持时间，曲名准确；切换文件不沿用另一曲的层号。
5. 导出所选声部WAV，检查非空PCM、音符存在时间窗与峰值；故意叠高音量时拒绝削波导出。
6. 下载NBS与导入字节一致。坏文件明确报错；未提供采样不能伪装播放；自定义音色缺采样明确失败。
7. 可选sidecar只有SHA匹配才显示语义分组，错误sidecar被拒绝。
8. 关闭网络/直接file://打开仍可播放，单文件不请求外部资源；无AI分轨复核等冗余面板。
